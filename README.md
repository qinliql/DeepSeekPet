# DeepSeekPet · 鱼团

<img src="dsh-pet/assets/default-avatar.png" width="96" alt="鱼团桌宠图标">

一个直接连接 DeepSeek API 的桌面陪伴程序。鱼团可以和你聊天、记住相处中的重要事情，也有自己的虚拟日常、伙伴和慢慢发展的故事。

**基于 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 改造，非官方项目，与 DeepSeek 或原作者不存在官方合作或背书关系。** 当前桌面版本为 **0.5.3**，主要在 Windows x64 上验证。

> 代码采用 MIT；角色形象与动画等素材有独立的非商业许可。请先阅读文末的许可与署名说明，不能将整个项目理解为可自由商用。

## 已实现的功能

| 模块         | 能做什么                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------- |
| 桌面聊天     | 无边框聊天窗口、历史分页、消息失败保留草稿；重新生成当前或历史回复；编辑用户消息后从该处继续 |
| 长期陪伴     | 聊天记忆整理与检索，记忆可以逐条查看、编辑、删除                                             |
| 自己的世界   | 慢节奏日常、持续故事、关系变化、兴趣成长、物件收藏和房间摆放                                 |
| 角色与世界书 | 添加角色卡、地点、规则等背景；支持 JSON 导入导出；初始四位同伴可扩展到100位                  |
| 用户参与     | 给鱼团提建议，记录剧情如何采纳、调整或放下建议                                               |
| 主动分享     | 故事发生与分享分离，合适时分享已经保存的趣事；未分享的日常也会记录                           |
| 生活日记     | 每次发展及时保存；真实聊天另设章节，标注时间、发言人与会话；支持导出                         |
| 现实信息     | 系统日期、时间与时区；IP城市级近似定位、手动城市、当前天气和三天摘要                         |
| 屏幕感知     | 先检查窗口稳定和画面变化，再择机截图；支持每日上限、冷却、排除词和暂停                       |
| 自定义       | 双方人设、头像裁剪、角色头像、主题色、字号、桌宠大小、待机节奏和作息                         |
| 费用与数据   | 月预算上限最高20元、调用前预算检查、分类账本、备份恢复和损坏快照恢复                         |

GPT、Claude、Grok、Gemini 等初始伙伴仅是**虚拟角色卡**，由同一个 DeepSeek 模型参考设定演绎，不会调用对应公司的模型，也不要求它们的账号。


## 从源码运行

需要 Git 和 **Node.js 24 LTS**（项目声明最低22.12；建议使用24）。不需要安装 DSH。

```powershell
git clone https://github.com/qinliql/DeepSeekPet.git
cd DeepSeekPet/dsh-pet
npm ci
npm run build
npm run ensure:electron
npm run start:app
```

`ensure:electron` 会下载 Electron，默认镜像与版本可在 `scripts/ensure-electron.mjs` 查看。也可用 `DSH_PET_ELECTRON_PATH` 指向已有的 Electron 可执行文件。

启动后，在设置中填入**自己的** DeepSeek API Key，启用对话、测试连接并保存。仓库不提供任何密钥。API调用会产生你自己的服务费用。

Windows 打包：

```powershell
npm run build
npm run ensure:electron
npm run dist
```

构建结果位于 `dsh-pet/dist-app/win-unpacked/`。请保留完整目录，不要只移动可执行文件。当前仓库提供源码与素材，不含本机私用安装包。

## 使用与自定义

右键桌宠只保留「聊天」「设置」「待办」。聊天窗口顶部可以切换聊天、生活与角色、设置和现实信息。

- **生活与角色 → 生活概览 → 世界节奏**：调整休息时段、静默多久进入自己的生活、故事间隔、主动分享冷却、每日次数、同时进行的故事上限及参与人数。
- **角色库 / 世界书**：添加背景人物与生活环境；故事编辑可以单独选择参与者与地点。
- **我的资料 / 鱼团**：修改人设和头像。公开版默认资料为通用示例，默认头像使用上游图标，没有打包私用照片。
- **设置 → 个性设置**：修改大小、字号、主题色和待机表现。点击音效关闭；拖拽松手后停在原位，惯性甩抛与碰撞反弹默认关闭，可以自行开启。
- **现实信息**：自动定位不准确时手动设置城市，也可关闭位置与天气查询。天气服务来自 [Open-Meteo](https://open-meteo.com/)，自动定位来自 [IPWho.is](https://ipwhois.io/)。

默认休息为 **02:00–08:00**，支持自定义和跨午夜。休息时暂停自动模型故事推进、主动分享与自动截图；你主动发消息仍会正常回复。

默认每两小时尝试一次故事、每天最多3次故事调用和2次主动分享。自动截图默认每天最多3次，并设冷却与本地变化检测。可在界面调整；模型调用仍受预算保护。

## 对话编辑与日记

每条普通助手回复下面有「重新生成」，用户消息下面有「编辑并重发」。修改历史位置会从那里重新生成，**后面的对话全部移除**；生成失败会保留原分支。主动分享没有对应提问，不提供重生成按钮。

日记包括虚拟故事、本地生活、现实观察和真实对话记录。编辑聊天会同步替换日记中的聊天分支，但不会让独立运行的世界故事倒退。恢复快照可能仍保留旧记录，不等同于安全擦除。

## 数据与隐私

Windows 默认数据目录：`%APPDATA%/WhaleCompanion/dsh-pet`，Chromium配置另存于同级目录。开发与打包版本默认共用此目录；隔离测试可设置 `WHALE_COMPANION_HOME`。

- API密钥保存在本机配置文件中，**不是操作系统保险库加密存储**。不要提交整个运行数据目录。
- 正常聊天、必要的记忆与世界上下文会发送给配置的模型接口；启用屏幕感知时，选中的缩小截图也会发送给模型。原始截图不写入故事日记。
- 查询位置与天气时会访问上述第三方服务；IP定位可能受代理或VPN影响，不能代表精确地址。
- 世界备份不含API密钥，但包含聊天、人设、头像和记忆等个人内容，**不要公开上传备份**。
- 账本按应用请求用量与设置单价计算，最高20元限制只覆盖本应用；其他客户端消费需要自行计入“启用预算前已花费”。价格变化时应更新单价。

仓库使用忽略规则排除密钥文件、运行记录、备份、日志、浏览器资料、私用头像和构建产物。上传前仍需检查自己新增的文件与截图。更多说明见 [SECURITY.md](SECURITY.md)。

## 当前边界

- 程序关闭时不会继续调用模型；重启后合并结算离线生活，不逐小时补发请求。
- 时间、位置、天气是已接入的现实能力，不包含任意联网搜索。
- 角色卡支持 JSON，尚不解析图片内嵌角色卡。
- 世界故事和记忆由模型生成，可能重复或判断错误，不能作为可靠的日程提醒或现实事实来源。
- 长期故事连贯性和自然搭话仍需持续使用验证。复杂的个人课表尚无专门排程编辑器。
- Windows x64 为主要验证平台，其他平台尚未进行完整验收。
